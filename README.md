## Targeted Learning for Inference on Data Fairness 

This repository contains code for my work on targeted learning and fairness (https://arxiv.org/abs/2502.04309). 

See [EXPERIMENTS.md](EXPERIMENTS.md) for current analysis names, output paths,
and commands, and the [manuscript workflow audit](docs/workflow-audit.md) for
the original findings and their resolution. Publication builds never launch
simulations; new computation uses explicit configurations and fresh run IDs.
[Retired workflow targets](archive/workflow_2026-10-09/README.md) are excluded
from the active `Snakefile`; their code and scientific records are preserved.
