# Historical exploratory notebooks

These notebooks are not the source of the manuscript figures or tables; the
supported workflow is documented in [EXPERIMENTS.md](../EXPERIMENTS.md).
Some notebooks retain inline copies of the old EIF variance formulas and
obsolete estimator APIs. Their saved intervals and coverage outputs should not
be used to support current manuscript claims.

The corrected manuscript and standalone experiments, their regenerated
artifacts, and the changes in interpretation are documented in
[the EIF regeneration report](../docs/eif-regeneration.md). Use the current
`tlfair` estimators and `analysis/` entrypoints for new work.
